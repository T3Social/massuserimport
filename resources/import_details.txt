*** CONFIGURABLE USER DETAILS ***

*** REQUIRED data ***************
*********************************
user.email:_____________The users email adress has to be unique.                                                          REQUIRED
profile.firstname:______Users first name.                                                                                 REQUIRED
profile.lastname:_______Users last name.                                                                                  REQUIRED

*** Further Details *************
*********************************
group_ids:______________Comma separated group ids user should be initially assigned to. To make a user admin,             Default: The group declared as available at registration with the smallest id. This is normally the "Users" group with id 2.
                        assign him to the admin group (normally id 1).
password.newPassword:___The user password.                                                                                GENERATED IF EMPTY: If left empty, a 15 sign long, safe and random password will be generated.
user.username:__________Unique name to identify users.                                                                    GENERATED IF EMPTY: Will be generated from profile.firstname and profile.lastname if empty. If a given username is already taken, a number will be appended. 
user.tags:______________User tags.                                                                                        Default: empty
user.language:__________The users preferred language.                                                                     Default: empty

Additional info:
* As an administrator, you can define new profile fields in the Admin->Profile view. You should be able to fill these with the massuserimport as well with the identifier profile.<your_field_name>. 
* Profile fields may have restrictions in the values that can be set to them. E.g. profile.date is of type type "date" and will be validated against that. profile.country accepts only country codes specified in ISO 3166.
